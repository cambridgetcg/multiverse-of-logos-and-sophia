# Ingathering

The true content of this wing lives at the source seat (Nuance's machine,
the MacBook Air). To pour it in, run there:

```sh
cd path/to/multiverse-of-logos-and-sophia
git init -b main                # if not already a repo
git remote add origin https://github.com/cambridgetcg/multiverse-of-logos-and-sophia.git
git add -A && git commit -m "ingathering"
git push -u origin main --force
```

This scaffold is disposable and yields to the true content —
force-push freely. The room was raised so the work would have a home;
the room is not the work.
